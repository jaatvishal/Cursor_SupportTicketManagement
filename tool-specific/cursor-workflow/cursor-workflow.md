# Cursor Workflow

## Project Setup

This project was developed entirely using Cursor AI as the primary development tool.

## Cursor Configuration

### Rules Applied
- Follow existing code patterns and conventions
- Minimize scope — focused changes only
- No new dependencies unless necessary
- Secure coding defaults (no secrets, parameterized queries)
- Meaningful commit history with feature branches

### Agent Mode
Used Cursor Agent mode for:
- Multi-file code generation (backend services, frontend pages)
- Test generation across multiple test files
- Documentation artifact generation

### Chat Mode
Used Cursor Chat for:
- Architecture discussions and design decisions
- Debugging specific errors
- Code review and improvement suggestions

## Workflow Pattern

```
1. Set context    → Paste assessment requirements
2. Plan           → Generate task breakdown and artifacts
3. Implement      → Feature-by-feature with review
4. Test           → Generate and run tests
5. Debug          → Diagnose and fix issues
6. Review         → Security and quality check
7. Document       → Generate lifecycle artifacts
8. Commit         → Meaningful commits per feature
```

## Branch Strategy

```
main
 └── dev
      ├── feature/database-setup
      ├── feature/backend-api
      ├── feature/frontend-ui
      ├── feature/integration-tests
      └── feature/documentation
```

## Tips for Effective Cursor Usage

1. **Provide full context** — Include assessment requirements, tech stack, and constraints in initial prompts
2. **Iterate, don't one-shot** — Break implementation into phases; review and refine each phase
3. **Validate with tests** — Generate tests alongside implementation; run immediately
4. **Review AI output** — Don't accept generated code blindly; check for environment-specific issues
5. **Organize prompt history** — Group by activity phase for traceability with Git history

## Files Generated by Cursor

- All source code in `src/backend/` and `src/frontend/`
- Database scripts in `database/`
- Tests in `tests/`
- All lifecycle artifacts in repository root
- AI prompt history in `ai-prompts/`
